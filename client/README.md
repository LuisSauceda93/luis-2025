# Cliente web

Cliente React y TypeScript de la aplicación.

Desde esta carpeta instala las dependencias y ejecuta el cliente:

```bash
npm install
npm run dev
```

Para ejecutar las pruebas:

```bash
npm test
```

Para generar la compilación de producción:

```bash
npm run build
```

El cliente espera que el servidor esté disponible en `http://localhost:3000`.
